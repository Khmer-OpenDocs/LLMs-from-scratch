# កូដពីឃ្លាំង upstream (Code mirror)

ថតនេះផ្ទុកចម្លងនៃ **ឯកសារកូដ និងទិន្នន័យ** ពីឃ្លាំង
[rasbt/LLMs-from-scratch](https://github.com/rasbt/LLMs-from-scratch)
(អាជ្ញាបណ្ណ Apache-2.0, (c) Sebastian Raschka) ដោយមិនបានកែប្រែតក្កវិទ្យាកូដ។

- រចនាសម្ព័ន្ធថតត្រូវបានរក្សាដូចដើម ដើម្បីឱ្យការ import ធៀបដំណើរការបាន។
- **មិនបានចម្លង**៖ ឯកសារ Markdown (អត្ថបទសៀវភៅ), រូបភាព, និង workflows —
  ព្រោះអត្ថបទសៀវភៅ និងរូបភាពពាក់ព័ន្ធតរូវបានដកចេញពីវិសាលភាពអាជ្ញាបណ្ណ Apache-2.0
  (ជាកម្មសិទ្ធិរបស់ Manning Publications)។
- Notebooks ត្រូវបានផ្តល់ជាកំណែ Khmer companion នៅថត `../ណូតប៊ុក-ខ្មែរ/`
  (កូដដូចដើម ១០០% + comments បកប្រែ + គ្មានអត្ថបទសៀវភៅ)។
