=====================================================================

ជំពូកនេះគ្របដណ្តប់ការរៀបចំទិន្នន័យអត្ថបទសម្រាប់ LLM — ដំណើរការពីអត្ថបទឆៅទៅជា
token រហូតដល់ការបង្កើត dataloader សម្រាប់ការបណ្តុះបណ្តាល។ បណ្ណាល័យពាក់ព័ន្ធសំខាន់
ដែល ``requirements.txt`` កំណត់សម្រាប់ជំពូកនេះគឺ ``tiktoken`` (>= 0.5.1)។

មេរៀនសង្ខេប (សិក្សាងាយ)
--------------------------

ការពន្យល់ខាងក្រោមជាអត្ថបទដើមរបស់សហគមន៍ ដើម្បីជួយឱ្យយល់គំនិតសំខាន់ៗមុនពេលអានកូដ៖

- **Token** — ឯកតាតូចបំផុតនៃអត្ថបទ (ពាក្យ កំណាត់ពាក្យ ឬអក្សរ) ដែលម៉ូដែលអាចដំណើរការបាន។
- **Vocabulary** — តារាងផ្គូផ្គាប់ token ↔ លេខគត់ (token ID)។ ទំហំរបស់វាកំណត់ទំហំស្រទាប់ embedding។
- **BPE (Byte Pair Encoding)** — វិធីសាងសង់ vocabulary ដោយផ្គុំគូអក្សរ/កំណាត់ដែលកើតឡើងញឹកញាប់ ធ្វើឱ្យពាក្យដែលមិនធ្លាប់ឃើញក៏បំបែកបានដែរ។
- **Embedding** — ការបំលែង token ID ទៅជាវ៉ិចទ័រលេខ ដើម្បីឱ្យបណ្តាញសរសៃប្រសាទអាចគណនាលើ "អត្ថន័យ"។
- **Sliding window + target shift** — អត្ថបទត្រូវបានកាត់ជាបន្សំបញ្ចូលប្រវែងថេរ ហើយ target គឺបន្សំនោះរំកិលទៅមុខ ១ token (ការព្យាករណ៍ token បន្ទាប់)។

ដំណើរការកូដក្នុងជំពូកនេះ៖

1. ផ្ទុកអត្ថបទឧទាហរណ៍ និងបំបែកវាជា tokens ដោយកន្សោមធម្មតា។
2. សាងសង់ vocabulary និង tokenizer V1 បន្ទាប់មក V2 (មាន special tokens)។
3. ប្រើ tiktoken (BPE របស់ GPT-2) ជា tokenizer ផលិតការ។
4. បង្កើត DataLoader ដោយ sliding window សម្រាប់ការបណ្តុះបណ្តាល។
5. បំលែង token IDs ទៅជាវ៉ិចទ័រដោយ embedding + positional embedding។
