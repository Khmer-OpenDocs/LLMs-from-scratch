ជំពូក ១៖ ស្វែងយល់ពី Large Language Models
=============================================

.. note::

   ប្រភព៖ ថត `ch01 <https://github.com/rasbt/LLMs-from-scratch/tree/main/ch01>`_
   និងតារាងមាតិកាក្នុង `README.md <https://github.com/rasbt/LLMs-from-scratch/blob/main/README.md>`_ របស់ upstream។

ជំពូកនេះជាជំពូកណែនាំអំពីគោលគំនិត — តារាងមាតិការបស់ upstream បញ្ជាក់ថា **"No code"**
(គ្មានកូដ) សម្រាប់ជំពូកនេះ។ វាដាក់មូលដ្ឋានគ្រឹះសម្រាប់ជំពូកបន្ទាប់ទាំងអស់
ដែលនឹងសរសេរកូដសាងសង់ LLM ពិតប្រាកដ។

មេរៀនសង្ខេប (សិក្សាងាយ)
--------------------------

ការពន្យល់ខាងក្រោមជាអត្ថបទដើមរបស់សហគមន៍ ដើម្បីជួយឱ្យយល់គំនិតសំខាន់ៗមុនពេលអានកូដ៖

- **LLM (Large Language Model)** — ម៉ូដែលសរសៃប្រសាទដែលត្រូវបានបណ្តុះបណ្តាលឱ្យព្យាករណ៍ token បន្ទាប់ពីអត្ថបទដ៏ច្រើន។ ចំណេះដឹងភាសា និងសមត្ថភាពបង្កើតអត្ថបទកើតចេញពីការបណ្តុះបណ្តាលនេះ។
- **Pretraining និង Finetuning** — ដំបូងម៉ូដែលរៀនពីទិន្នន័យគ្មានស្លាក (pretraining) បន្ទាប់មកត្រូវបានកែសម្រួលបន្ថែមសម្រាប់កិច្ចការជាក់លាក់ (finetuning) ដូចជាចំណាត់ថ្នាក់ ឬការឆ្លើយតបតាមការណែនាំ។
- **ត្រកូល GPT (decoder-only)** — ម៉ូដែលដែលបង្កើតអត្ថបទម្តងមួយ token ដោយប្រើ attention លើ tokens ដែលនៅពីមុខវា។
- **ហេតុអ្វីសាងសង់ពីមូលដ្ឋាន?** — ការសរសេរ tokenizer, attention និង training loop ដោយខ្លួនឯង ផ្តល់ការយល់ដឹងជ្រៅជាងការគ្រាន់តែហៅបណ្ណាល័យ។
